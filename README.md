# Nachhilfe – TermeTrainer

Lern-App zur Vorbereitung auf die 1. Mathe-Schulaufgabe (Terme), 7. Klasse.

- 7 Themen mit je 10 Aufgaben in 3 Schwierigkeitsstufen (Grundlagen, Fortgeschritten, Profi)
- Lösung erst auf Knopfdruck, danach selbst als richtig oder falsch bewerten
- 1 Punkt pro richtiger Aufgabe, falsche Aufgaben kommen zur Wiederholung zurück
- 🔥 Flamme und lachende Smileys bei 5 richtigen Aufgaben in Folge
- Fortschritt wird im Browser gespeichert

**Starten:** `index.html` im Browser öffnen.
